# Code of Conduct

## Our Commitment

Crop Health Triage is committed to a respectful, inclusive, and constructive environment for everyone who participates in the project.

## Expected Behavior

Contributors should:
- communicate respectfully and professionally
- welcome different technical backgrounds and perspectives
- provide constructive feedback
- focus discussions on the work and project goals
- respect other contributors' time and contributions
- report problems responsibly

## Unacceptable Behavior

The following is not acceptable:
- harassment or discrimination
- personal attacks or insults
- threats or intimidation
- publishing private information without permission
- deliberate disruption of project collaboration
- hateful or sexually inappropriate content
- knowingly introducing malicious code or credentials

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this code of conduct and may restrict participation when necessary.

## Reporting

For conduct concerns, contact the project maintainer privately rather than publishing sensitive details in a public issue.

## Scope

This applies to project discussions, issues, pull requests, code reviews, and other project spaces where contributors participate in the Crop Health Triage project.
